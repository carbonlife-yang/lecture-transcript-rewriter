# 讲课能力评分表

> **用来评估讲师讲课能力的 10 维度评分表**。可以自评,也可以他评(同事/学员给讲师打分)。

---

## 评分说明

- 每个维度 1-5 分
- 1 分 = 很差,需要大改
- 2 分 = 较差,需要重点改
- 3 分 = 及格,有改进空间
- 4 分 = 良好,小修即可
- 5 分 = 优秀,可作范本
- 加权平均得到总分
- 评分人:讲师自评 / 同事评 / 学员评(分别打分)

## 评分等级

| 总分 | 等级 | 含义 | 建议行动 |
|------|------|------|----------|
| ≥ 4.5 | 优秀讲师 | 可作为标准范本,沉淀为组织知识资产 | 让他/她继续讲课,沉淀为模板 |
| 4.0-4.5 | 良好讲师 | 小修小补即可 | 针对待优化点改 1-2 轮 |
| 3.5-4.0 | 合格讲师 | 需要补全漏讲 + 调整时间 | 按问题分析表重写,1 轮优化 |
| < 3.5 | 需重做 | 核心模块缺失或结构失衡 | 需要资深讲师带,或按 Skill 重写 |

## 改进建议(给评分 < 4 分的维度)

| 维度 | 改进建议 |
|------|----------|
| 1. 知识覆盖度 | 看漏讲清单,逐项补全 |
| 2. 时间分配 | 重新设计模块时长 |
| 3. 案例演示 | 每个核心概念加案例 + 现场演示 |
| 4. 结构清晰 | 重新画主线,一句话讲清 |
| 5. 互动设计 | 每个模块后加互动节点 |
| 6. 语言流畅 | 多演练,修口误 |
| 7. 重点突出 | 加粗+下划线 + 反复强调 |
| 8. 答疑设计 | 加客服路径,答疑留时间 |
| 9. 收尾设计 | 加反馈引导 + 下节预告 |
| 10. 学员友好度 | 从 0 开始,不要预设基础 |
