# 讲师口播稿 docx 文档结构模板

> **这个模板描述"讲师口播稿 docx 长什么样"**,AI 生成时按这个结构排版。

## 文档结构(必须包含)

### 1. 封面(必须)

```
┌────────────────────────────────────┐
│  [课程名]                           │  ← 18pt 加粗 主色
│  讲师逐字稿 v[N]([时长]·[风格标签]) │  ← 13pt 副标题
│                                    │
│  [1 段说明文字]                    │  ← 10.5pt 灰色
│  例:8 大模块,正常语速 230 字/分    │
│                                    │
│  ┌────┐┌────┐┌────┐┌────┐         │
│  │项目││内容││项目││内容│  ← 表格 │
│  └────┘└────┘└────┘└────┘         │
│  课程主题  | ___   | 口播总时长 | ___  │
│  适用受众  | ___   | 框架版本   | ___  │
└────────────────────────────────────┘
```

**封面元数据表(4 项必填)**:
- 课程主题
- 口播总时长
- 适用受众
- 框架版本

---

### 2. 全篇节奏表(必须)

| 编号 | 模块 | 时长 | 核心目标 |
|------|------|------|----------|
| 1 | 模块名 | 约 10 分钟 | 核心目标 |
| 2 | 模块名 | 约 5 分钟 | 核心目标 |
| ... | ... | ... | ... |

**通常 8 个模块**,每个一行。

---

### 3. 模块正文(每个模块 1 段标题 + 5-15 段正文)

#### 模块标题格式

```
[深蓝色背景块] 模块 N · [模块名](约 X 分钟)
```

#### 模块内常见段落类型

**① 开场段(每个模块第 1 段)**
- 1-2 句话过渡
- 引入本模块核心问题

**② 核心讲解段(每个模块 5-10 段)**
- 详细讲解知识点
- 加粗+下划线强调关键概念首次出现

**③ ★ 重点框(每个模块 1-3 个)**
```
┌────────────────────────────────────┐
│ ★ 重点:[核心结论/关键金句]          │  ← 浅黄色背景
└────────────────────────────────────┘
```

**④ 互动提示框(每个模块 0-2 个)**
```
┌────────────────────────────────────┐
│ 【互动/讲师提示】[互动建议/演示提示] │  ← 浅灰色背景
└────────────────────────────────────┘
```

**⑤ 案例段(每个模块 1-3 个)**
- 真实业务场景举例
- "比如..." 开头

**⑥ 小结段(每个模块最后 1 段)**
- 1-2 句话回顾本模块要点
- 过渡到下个模块

---


#### 附录 3:口播字数与时长自检

| 模块 | 内容 | 目标时长 | 预估字数 |
|------|------|----------|----------|
| 1 | | 约 X 分钟 | 约 Y 字 |
| ... | ... | ... | ... |
| 合计 | | 约 X 分钟 | 约 Y 字 |

注:慢速 200 字/分约 X 分钟,正常 230 字/分约 Y 分钟,快速 250 字/分约 Z 分钟。

#### 附录 4:漏讲分析对照表(可选)

## 强调规则(必须遵守)

### 加粗+下划线 双重强调

- 每个关键概念**首次出现**时加粗+下划线
- 段落开头有核心词时也加粗+下划线

**常见强调词类型**:
- 产品/工具名:多维表格、飞书、Excel、AI
- 字段名:文本、自动编号、人员、单选、关联字段、公式
- 视图名:表格视图、看板视图、画册视图
- 权限概念:数据表权限、字段权限、选项权限、视图权限
- 核心数字:90 分钟、300 个、5 万行、200 万行
- 关键原则:基于角色配置、先角色后人员、保存并预览
- 强调类:三样本事、核心数字、关键动词

### ★ 重点框(浅黄色背景)

- 每个模块 1-3 个
- 放核心结论/关键金句
- 不要泛滥(否则失去意义)

### 互动/讲师提示框(浅灰色背景)

- 现场演示提示
- 评论区互动提示
- 不要每段都加

## 风格化(讲师档案驱动)

AI 改写时,把讲师档案里的内容加进去:

| 档案项 | 应用到稿子 |
|---|---|
| 口头禅(哎/好/对吧/大家想想) | 段落开头、过渡句 |
| 案例习惯(老板突然要数据) | 案例段 |
| 称呼(各位伙伴/同事/大家) | 全文统一 |
| 风格(轻松/严肃/技术流) | 语序、句长、段长 |

## docx 排版规范(技术细节)

| 元素 | 规范 |
|---|---|
| 主标题字号 | 18pt 加粗 主色 |
| 模块标题字号 | 11pt 加粗 白色(深蓝色背景) |
| 正文字号 | 11pt 默认 |
| 重点框字号 | 11pt 加粗 深棕色(浅黄色背景) |
| 互动框字号 | 10pt 灰色(浅灰色背景) |
| 表格表头 | 10pt 加粗 白色(深蓝色背景) |
| 表格正文 | 9.5-10pt 黑色 |
| 行距 | 1.5 倍 |
| 段后间距 | 4pt |
| 段落首行缩进 | 0.75 cm |
| 左右页边距 | 2 cm |
| 上下页边距 | 2 cm |

## Python 实现参考

```python
from docx import Document
from docx.shared import Pt, Cm, RGBColor
from docx.enum.text import WD_ALIGN_PARAGRAPH
from docx.oxml.ns import qn
from docx.oxml import OxmlElement

doc = Document()

# 标题
p = doc.add_paragraph()
run = p.add_run('多维表格基础功能培训')
run.font.size = Pt(18)
run.font.bold = True
run.font.color.rgb = RGBColor.from_string('1F4E79')

# 副标题
p = doc.add_paragraph()
run = p.add_run('讲师逐字稿 v1(90 分钟·轻松+案例驱动)')
run.font.size = Pt(13)
run.font.color.rgb = RGBColor.from_string('6E6E6E')

# 封面表
# ... (略)

# 模块标题(深蓝色背景)
def add_stage_label(doc, label):
    p = doc.add_paragraph()
    run = p.add_run(f'  {label}  ')
    run.font.size = Pt(11)
    run.font.bold = True
    run.font.color.rgb = RGBColor.from_string('FFFFFF')
    # 背景色
    pPr = p._p.get_or_add_pPr()
    shd = OxmlElement('w:shd')
    shd.set(qn('w:val'), 'clear')
    shd.set(qn('w:color'), 'auto')
    shd.set(qn('w:fill'), '1F4E79')
    pPr.append(shd)

# ★ 重点框(浅黄色)
def add_highlight(doc, text):
    p = doc.add_paragraph()
    run = p.add_run('★ 重点:' + text)
    run.font.size = Pt(11)
    run.font.bold = True
    run.font.color.rgb = RGBColor.from_string('8B4513')
    pPr = p._p.get_or_add_pPr()
    shd = OxmlElement('w:shd')
    shd.set(qn('w:val'), 'clear')
    shd.set(qn('w:color'), 'auto')
    shd.set(qn('w:fill'), 'FFF2CC')
    pPr.append(shd)

# 加粗+下划线段落(多强调)
def add_para_multi_emph(doc, segments):
    p = doc.add_paragraph()
    for text, is_emph in segments:
        run = p.add_run(text)
        run.font.size = Pt(11)
        if is_emph:
            run.font.bold = True
            run.font.underline = True

# 互动提示框(浅灰色)
def add_note(doc, text):
    p = doc.add_paragraph()
    run = p.add_run('【互动/讲师提示】' + text)
    run.font.size = Pt(10)
    run.font.color.rgb = RGBColor.from_string('6E6E6E')
    pPr = p._p.get_or_add_pPr()
    shd = OxmlElement('w:shd')
    shd.set(qn('w:val'), 'clear')
    shd.set(qn('w:color'), 'auto')
    shd.set(qn('w:fill'), 'F2F2F2')
    pPr.append(shd)

# 输出
doc.save('课程名_讲师口播稿_v1.docx')
```
